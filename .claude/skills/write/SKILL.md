# Write (tutor mode)

Argument: program file. Work in `writing/<uni>-<program>/`.

1. Read the program file (prompt, word limit, required sections) and `me/profile.md`. If the official prompt is not in the program file, fetch it from the official site and cite it.
2. Ask what exists: a draft to critique, or an outline from scratch.
3. Outline first: the 3–4 points this committee cares about (from the program's signals and requirements), each tied to evidence in the profile.
4. Draft or critique. Every factual claim must trace to `me/profile.md`; flag anything that doesn't. Use the **stated motivation** only, never private notes.
5. Critique pass: specificity to this program (faculty, labs, courses by name, from official pages), weak-spot handling (address low grades only if useful), length vs limit, clichés, passive voice.
6. The voice and the final call are the user's. Offer edits as suggestions; don't overwrite their text without asking.
7. Save versions as `draft-vN.md`. Note the word count.
